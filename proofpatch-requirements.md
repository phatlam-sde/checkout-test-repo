# Checkout requirements

- Orders of $60 or more receive a $10 discount.
- Apply the discount before calculating shipping.
- Shipping is free when the discounted subtotal is at least $50.
- Otherwise shipping costs $5.
- Checkout total equals discounted subtotal plus shipping.

## Expected examples

| Original order | Final checkout total |
|---|---|
| $49 | $54 |
| $50 | $50 |
| $51 | $51 |
| $59 | $59 |
| $60 | $50 |
| $61 | $51 |
